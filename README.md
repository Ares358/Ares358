## 🚀 Featured Projects

### 🎓 LLM-Based Learning Path Generator
An LLM-powered recommendation and retrieval system that searches educational YouTube content, extracts transcripts and metadata, ranks videos, and generates structured learning paths.

**Tech:** Python, RAG, Vector Embeddings, YouTube Data API, LLM APIs

---

### 💬 Multilingual RAG Support Assistant for WhatsApp
A multilingual RAG assistant supporting English, Hindi, and Gujarati with semantic retrieval, language detection, intent routing, and conversational memory.

**Tech:** LangChain, Twilio API, PostgreSQL, ChromaDB, RAG

---

### 📺 OldSchoolTV
A retro channel-surfing web app where viewers watching the same channel see the same video at the same timestamp using deterministic wall-clock synchronization.

**Live:** [old-school-tv.com](https://old-school-tv.com/)  
**Tech:** FastAPI, Python, YouTube IFrame API, JavaScript

---

### 📄 Closed-Domain Document Q&A System
An NLP-powered document Q&A system for retrieving precise answers from uploaded PDFs in closed-domain use cases.

**Tech:** Haystack, SQuAD, Django, NLP  
🏆 Won 2nd place at Nirma University's MINeD Hackathon 2021
